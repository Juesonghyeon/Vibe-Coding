# 1. 주제
  두 수를 입력 받아서 원하는 사칙연산을 하는 간단한 앱

# 2. 기능
- 두 개의 수를 입력받는다.
- 사칙연산을 선택
- 계산버튼을 누르면 결과를 화면에 출력

# 3. 조건
- 숫자만 입력받는다.
- 나누기는 실수표현 가능
- 소수점은 2째자리까지 나타냄

# 4. 디자인

## 4.1 배경 디자인
- 배경은 밝은 회색계열
- margin, padding 0
- UI는 화면 중앙에 위치

## 4.2 기능 디자인
- input은 라운딩 처리
- width, height는 알아서 해
- focus css 적용
- 버튼은 푸른색 계열로 디자인
- css는 폴더만들어서 별도 파일로 관리

# 5. 기능구현
- 자바스크립트는 별도 파일로 분리하여 폴더로 구분
- html 요소를 가져올 때 querySelector 사용
- 유효성 체크 필수

# 6. 기술스펙
- html, css, js 로만 프로그래밍
- 외부라이브러리 사용 금지
- 필요할 경우 허가 반드시 받아야 함
